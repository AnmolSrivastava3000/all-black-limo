# All Black Limo LLC — Seattle Chauffeur Experience

A luxury, conversion-focused web application built for **All Black Limo LLC (Seattle, WA)** as part of the Saywa Digital Full Stack Web Developer practical assessment.

## Key Features Implemented
- **Editorial Luxury Aesthetic**: Charcoal & obsidian surfaces (`#0A0A0C`) paired with restrained champagne gold (`#C5A059`) accents, `Cormorant Garamond` serif headings, and `Plus Jakarta Sans` UI typography.
- **Verified Local Grounding**: Incorporates genuine business data for All Black Limo LLC, including `(206) 672-8281` click-to-call dispatch, `reservations@allblacklimoseattle.com`, SeaTac Airport (SEA), Pier 66 & Pier 91 cruise terminals, and Seattle/Bellevue/Tacoma/Gig Harbor service coverage.
- **Interactive Demo Quote Engine**: Validates all 6 core trip parameters (Pickup, Drop-off, Date, Time, Passengers, Vehicle Class), offers quick-select Seattle hub chips, prevents identical pickup/dropoff entries, and presents a transparent demo confirmation state with pre-filled dispatch email handoff.
- **Technical SEO & Accessibility**: Includes `LocalBusiness` + `LimousineService` Schema.org JSON-LD, Open Graph tags, semantic HTML landmarks, keyboard navigation, and accessible form error alerts.
